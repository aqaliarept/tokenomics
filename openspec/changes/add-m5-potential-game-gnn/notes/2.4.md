## `train/producer_read.py`
- **`pilot` (L3):** reads a train run's monitor rows at a generation (default 20).
  - g_tr = the equal-weight mean over the 16 monitor world-episodes of (centre − rf3), both at
    replicates 0 / 1 (equal to the driver's `monitor.csv` g_tr; test).
  - F_tr = M4's floors rule via `order_es_validate.mean_comp` / `monitor_cells` (atlas-spread SE,
    own 3 SE with the n = 1 rule).
  - `feasible` / `unresolved` → `pilot_g<generation>.json`.
- **`validate` (L5):** plays both seeds' candidates (latest checkpoint, the bar's normaliser), rf3,
  k4 and `entity_planner`, with MWWk at replicates 0 / 1. The worlds are the loaded atlas v2
  validation worlds at 12 and 42, 8 episodes per world (M4's validation stage), observer on.
  - The reading per v2: kill → transfer_failure → success → plateau.
  - It also reports the selection, `stock_heavy`, the reference comparisons, the per-arm flags
    (deaths, run-down / starvation shares) and the loss classes.
  - Real runs need: both runs complete, real, at generation 40, under v2 and the bar's
    normaliser, seeds 0 and 1; the registered atlas; a 40-hex commit; horizon 100; 8 episodes; no
    filters.
- **`heldout` (L6):** the selected candidate (from the L5 read's `reading.json` / pins), rf3 and
  the references on the held-out worlds (stage `m5-heldout`, 8 episodes, replicates 0 / 1), gated
  on the loaded ones. Reading: `confirmed` / `not_confirmed`.
  - A real run also needs a real L5 `success`, plus the ledger's single pending entry for
    `held-out/m5-producer`, with this θ and this package tree (`provenance.source_fingerprint`).
  - The read never writes the ledger.
- **`recompute`:** rebuilds `reading.json` from `episodes.csv` and the pins (the atlas file must
  match its pinned SHA). MATCH 0, MISMATCH exit 2.
- **`ledger-pending` / `ledger-close`** (M4 design D9's C0 / C1 rule):
  - pending records C0 = HEAD, the package tree hash, θ, the atlas hash and the date, and is
    refused when any entry exists for the key;
  - close records C1 and the EXP path, and only works from pending (done / invalid are final).
  - The ledger lives at `experiments/m5_heldout_ledger.json`.
- **`producer_es` additions:** jobs with `observe` attach the routing tracer and the supply observer
  (loss classes in the read rows); `play(columns=)`; pre-registration v2 (`registered_prereg(version)`,
  `PREREG_V1_*` kept).
