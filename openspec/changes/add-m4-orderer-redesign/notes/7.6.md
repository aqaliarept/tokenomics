## Design choices (one line each; settled from the sources)
- **Combination:** a logit add on MWW's log-weights, p ∝ w^(1/τ) · exp((Δ − max Δ) / τ), which
  is D5's `(b + Δ) / τ` with b = log w. It is computed multiplicatively so θ = 0 reproduces
  MWWk's weights bit for bit. An unmakeable producer is never drawn while another is makeable.
- **Code shape:** a subclass `MWWBasePolicy` plus `make_policy`. `PerOrderPolicy`'s source is
  inside the v1 / v2 normaliser fitting-code hash (`NORMALISER_CODE_DEFS`), and editing it broke
  v1 / v2 re-freeze; that is why it is untouched. v3 pins the subclass and MWWk helper sources
  in `es.base.code.sha256`.
- **Noise margin:** EXP-0068's constants are kept. They were measured on the TS-base A0, and
  re-measuring needs a run the decision does not include. The references are the new bar's A0
  rows.
- **Plateau clause (ii):** carried from EXP-0060 val-seed0 (A2-R2 − A1 = −14.1 within 39.8),
  because A2 is not re-run.
- **No probe:** the user decision licenses the run, and a v3 run refuses a probe reading.
