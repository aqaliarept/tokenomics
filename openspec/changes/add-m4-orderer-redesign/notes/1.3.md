## Definitions chosen (also in §a / §b)
- **First confirm episode** = `teacher_audit.first_confirm_seed(view)` =
  `episode_seeds(id, n, CONFIRM_STAGE)[0]`. This is generation order, which is EXP-0052's csv
  row order, not the sorted seed: for 12-0060 it is 1295251592, not 7166650. It equals EXP-0056's
  `episode` on all three worlds (rows found and matched).
- **Agent turn** = one ordering-policy call for one ordering agent in one cycle. Under
  `joint_stack` an agent is one (source, product) stream, so a turn has one product and one class.
  The probe asserts this. Active turn = ≥ 1 order with quantity > 0 in `incoming` (re-bids
  included).
- **Concurrent same-product order group** = the orders routed in one cycle for one product, when
  there are ≥ 2 (all agents).
- **Across-agent share**: group version (share of groups with ≥ 2 distinct agents; the task's
  definition, used for the trigger), pair version (cross-agent order pairs / all pairs; the
  composition measure, closer to D11's "mostly across agents") and order version. They differ
  by ≤ 0.09 here and all are ≥ 0.877, so the choice does not matter.
  - Primary scope: products with ≥ 2 declaring producers. On these worlds every product has
    ≥ 2, so scope "all" is identical.
- **(a) trigger rule** (D11 names no world count): MWW, < 0.5 on ≥ 2 of 3 worlds, as for (b).
  Every cell is listed; none of the 10 cells (any arm, incl. 42) is below 0.958, so any rule gives
  "not fired".
- **Completion rate** = completed / routed units over the episode, without D5's 1-unit prior
  (D3's measure takes the raw own rate; cells need ≥ 3 routed units anyway).
  - `agent_history_dispersion`: population SD across agents (sample SD reported beside it; it is
    higher and changes no outcome).
  - `routed_share_dispersion`: median over pooled (product, agent pair). Products need ≥ 2
    declarers; agents need ≥ 3 routed units of the product. The per-product-median variant is
    reported beside it.
