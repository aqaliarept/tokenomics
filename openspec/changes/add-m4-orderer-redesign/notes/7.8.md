## Code (`train/order_es.py`, `train/order_es_validate.py`)
- **`run_noise_floor_bar`** (`--mode noise-floor --bar-dir <bar> --base mww`, no `--probe-dir`):
  - plays A0 on the bar's own base, re-keyed at r0..r4, on **all** the bar's training
    world-episodes (EXP-0070: 128, so 640 jobs);
  - writes `noise_floor.csv`, `reproduction.csv` (r0 must equal the bar's A0 rows) and
    `margins.json`;
  - `--recompute` rebuilds `margins.json` offline (MATCH / MISMATCH);
  - pins no probe files;
  - a real run needs a real bar on v3's base, K = 4 and pre-registration v3;
  - the probe-file path (EXP-0068) is unchanged.
- **`margins_doc(rows)`** gives the registered formula (`noise_margins`, c = 2) and re-keyed A0's
  self-flags without / with the margin. Its guards are derived from its own r0 rows (`r0_bar`,
  the bar's rule: equal to the bar's A0 columns where r0 reproduces it, tested on EXP-0068).
  It also gives the ≤ 5% target (floor(0.05 × episodes)) and the leave-one-world-out refit
  (reported only).
- **v4:** `registered_sections(4)` = v3 with `es.disqualification.noise_margin` =
  `v4_margin_registration()`. That is computed from `train/registry/es_noise_floor_m4_v4.csv`
  (EXP-0071's rows, SHA-256 recorded) and cached per file; without the file v4 refuses.
- **Freeze (7.9b, local, no pod):** `order_es_validate --mode freeze --prereg-version 4
  --noise-floor <EXP-0071>/noise_floor.csv`:
  - stages the CSV into the package, never over different rows;
  - refuses a margin that misses the target;
  - writes `es_prereg_m4_v4.json`;
  - then pin `PREREG_V4_SHA256` (empty until then, so a v4 file is refused at launch) and
    commit.
- **v1–v3:** re-freeze MATCH; nothing else changes for them.
