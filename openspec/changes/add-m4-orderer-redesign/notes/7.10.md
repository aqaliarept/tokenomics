# 7.10: `utwf_active`, rules PINNED (supervisor go, 2026-11-04), before any code or data

Base 019abc1. Source: tasks.md 7.10, the user decision 2026-11-04 ("count only agents likely to
order this cycle; share each producer's capacity across its products"), notes/5.5.md
deviations 1 and 4, EXP-0067 RESULT.md. `utwf` itself is unchanged.

## What an ordering agent can observe (ADR-0058 information set)
Its own orders, and its product stream view:
- **product stats** for its own product p: the consumer-demand EMA `recent_average_cycle_demand`,
  `open_demand_quantity` and the rejected-demand EMA;
- **producer rows** (aggregates per producer);
- **producer-product rows** for p: `makeable_qty_now`, and `recent_routed_qty` = the telemetry
  EMA (α = 0.3) of the units of p routed to that producer per cycle, by all agents, past cycles
  only;
- its own agent-local history.

**Not observable:** how many agents ordered p in any cycle. No count of distinct ordering agents
is published, and other agents' current-cycle orders are excluded by ADR-0058. So the task's
"EMA of past per-cycle counts of agents that ordered p" is not available to the agent.

## Fix 1 (PINNED, supervisor-approved 2026-11-04): M_p → the expected total arrivals of p
In uTWF, M enters only through M · a^(m), the paper's estimate of the round's total arrivals
(§4.1). The proxy estimates those arrivals directly from published past data:
- Â_p = Σ_n `recent_routed_qty`(n, p): the EMA of all units of p routed per cycle by all agents.
  It covers consumer and producer (replenishment / investment) orders, past cycles only, and is
  already in the agent's stream view. α = 0.3 is the domain telemetry's, registered.
- **Water levels:** WaterLevel(Q, M a) → WaterLevel(Q, Â), and WaterLevel(Q, (M − 1) a) →
  WaterLevel(Q, Â − a), with Â := max(Â_p, a^(m)), so the agent counts at least its own load.
  Equivalently M̂_p = Â / a^(m) (a rational, ≥ 1).
- **Degenerate case:** Â ≤ a^(m) (e.g. cycle 1, no history) gives M̂ = 1, JSQ, as uTWF's M = 1
  case.
- **Reduction:** with Â replaced by M_p · a^(m) (the configured count), this is exactly `utwf`
  (tested).

**Rejected alternative:** Â from the consumer-demand EMA (`recent_average_cycle_demand`). It is
also observable but misses the producer streams' orders of p, so it under-counts arrivals.

## Fix 2 (PINNED: Option A, supervisor decision 2026-11-04): each producer's spare shared across the products it declares
`makeable_qty_now(n, p)` assumes all of producer n's capacity serves p. The proposed queue input
is

    spare_n(p) = floor(makeable_qty_now(n, p) · w_n(p))

**Option A (recommended).** w_n(p) is p's share of n's recent routed load among the products n
declares that use a capacity type p's recipe uses:

    w_n(p) = (R_n(p) + ε) / Σ_{x ∈ C_n(p)} (R_n(x) + ε)

- R_n(x) = telemetry `routed_ema`(n, x) (past cycles, published per producer-product);
- C_n(p) = the products n declares that share a capacity type with p, p included;
- ε = 1 unit keeps a product with no history at an equal share; with no history at all,
  w = 1 / |C_n(p)|.
- **Legality (supervisor decision, 2026-11-04):** Option A is chosen.
  - R_n(x) is a published past producer-product average (the telemetry EMA, folded at the end of
    each cycle, so it holds past cycles only). It is never another agent's current-cycle order or
    routing, so ADR-0058 holds.
  - It reaches past the stream view's own fields, which is acceptable because `utwf_active` is a
    diagnostic router: never trained, never in the roster, never a deployed policy's input.

**Option B (not chosen; strictly in view, static).** w_n(p) = 1 / |C_n(p)| from the configuration (`produces`
and the recipes are public). It is not load-scaled.

**Common to both options:**
- The integer floor keeps the paper's integer queues. A producer whose share rounds to 0 is
  still eligible; uTWF then treats it as a long queue.
- **Reduction:** w ≡ 1 (no sharing) gives `utwf`'s queues exactly (tested).

## Pinned constants
- α = 0.3: the domain telemetry's EMA, used as published.
- ε = 1 unit.
- C_n(p) = the products in n's `produces` whose recipe `require` shares at least one capacity
  type with p's, p included.
- w_n(p) is exact (Fractions); spare_n(p) = floor(makeable_qty_now(n, p) · w_n(p)).
- T = max(Â_p, a^(m)), with Â_p = Σ_n routed_ema(n, p) over every producer as an exact
  Fraction of the published float.
- p_n is uTWF's Eq. (29) with M a^(m) → T and (M − 1) a^(m) → T − a^(m). T ≤ a^(m) gives JSQ.
